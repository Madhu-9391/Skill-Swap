# Skill-Swap Backend

🚀 Backend service for the Skill-Swap platform built using Node.js, Express.js, MongoDB, and Socket.IO, enabling real-time communication, secure authentication, and scalable multi-user collaboration workflows.

---

## Features

- RESTful API architecture
- Real-time communication using Socket.IO
- JWT-based authentication and authorization
- User profile and skill management
- Skill exchange and collaboration workflows
- Secure backend routing and middleware handling
- MongoDB database integration
- Concurrent request and message handling
- Scalable modular backend architecture
- Optimized API and database workflows

## Installation

### Clone Repository

```bash
git clone https://github.com/Madhu-9391/Skill-Swap-backend.git
cd Skill-Swap-backend
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

Create a `.env` file in the root directory:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLIENT_URL=your_frontend_url
```

### Run Development Server

```bash
npm run dev
```
